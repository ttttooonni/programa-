# Javier · Barbate 2027 — PWA

PWA informativa para consultar áreas de trabajo, territorio, propuestas publicadas y fuentes.

## Publicar en GitHub Pages
1. Abre Settings → Pages.
2. Selecciona Deploy from a branch.
3. Elige main y la carpeta /(root), y guarda.
4. URL esperada: https://ttttooonni.github.io/programa-/

## Incluye
- Diseño responsive para móvil, tableta y escritorio.
- Navegación por áreas, esquema territorial y fichas modales.
- Buscador y filtros.
- Manifiesto PWA y service worker con caché básica.
- Fuentes institucionales y del partido.
- Etiquetado de antecedentes y fichas pendientes.

## Criterio editorial
Verifica cada dato y fecha antes de publicarlo. Una propuesta no equivale a una actuación ejecutada. Cada ficha debe incluir fuente, competencia, financiación, plazo y estado. El esquema territorial es orientativo, no un mapa oficial completo.

## Imágenes
La portada reutiliza el retrato publicado en el repositorio javier. Para una publicación estable, copia las fotografías autorizadas a una carpeta assets de este repositorio y actualiza las rutas. No asignes fechas o contextos a fotografías sin comprobar su publicación original.
